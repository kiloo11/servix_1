# Изменения

Версия панели живёт в `package.json` — сервер читает её оттуда и отдаёт в `meta.version`,
по ней же работает проверка обновлений. Релиз = тег `vX.Y.Z` в репозитории: панель
сравнивает свою версию с последним релизом (а если релизов нет — с максимальным тегом).

## 2.0.1

- Хотфикс: карточки в «Финансы» на мобильных выстраивались в один
  столбец вместо сетки 2×N.

## 2.0.0

- Бэкенд полностью переведён на Python (FastAPI) — Node.js (`server.js`)
  убран из репозитория и из production-образа.
- Разделы «Дашборд», «Статистика» и «P&L» объединены в один раздел
  «Финансы» с вкладками: Подписки, P&L, Платежи, Курсы валют.
- «Провайдеры» перенесены во вкладку внутри «Ресурсов» — теперь один
  раздел с вкладками «Записи» и «Провайдеры».
- У записей появилось поле «Описание».
- Убрана нерабочая кнопка самообновления из настроек — версия панели
  видна в сайдбаре, обновление вручную (`docker compose pull && up -d`).
- Карточка записи: реальный срок истечения и дата в пиллах сверху,
  IP/провайдер выровнены сеткой со стоимостью/платежами ниже.
- Локальная разработка: `npm run dev` больше не грузит процессор на
  600–700% (Turbopack больше не сканирует весь репозиторий), `uvicorn --reload`
  больше не перезапускается от правок внутри `.venv`.

## 1.3.1

- Хотфикс: в модалке платежей кнопка добавления могла уезжать за пределы
  окна, если название валюты в селекте было длинным (например,
  «Российский рубль») — сетка `.quick-payment` не давала колонкам сжиматься.
  Текст в `AppSelect` теперь обрезается многоточием вместо переноса/
  раздувания ширины — тот же фикс защищает все остальные селекты в панели
  от такого же переполнения.
- Селекторы валюты (запись, платёж, продление, настройки) показывают знаки
  €/₽/₮ вместо полных названий — короче, не переносится, и устраняет саму
  причину переполнения выше.

## 1.3.0

- Единая типографическая шкала: 16 разномастных размеров шрифта собраны
  в 10 именованных токенов (`--text-2xs`…`--text-4xl`).
- Прогноз расходов на графике «Расходы по дням» — пунктирная линия на
  2 недели вперёд по датам продления активных серверов.
- Сортировка записей внутри категорий: вручную, по ближайшему платежу,
  по провайдеру, по стране.
- Карточка записи: акцент на статусе истечения (цвет/иконка совпадают
  с рамкой карточки), понятные подписи у сумм, убраны дублирующиеся
  элементы (повторный бейдж категории, лишняя строка «Платёж»).
- Плейсхолдер с первой буквой названия корректно показывается вместо
  битого favicon (в том числе если картинка не загрузилась).
- Сайдбар: карточка сводки разделена на «Ресурсы», «Финансы» и «Курсы
  валют»; в «Финансах» — доход и прибыль от бота за месяц с трендом
  к прошлому месяцу; курсы валют можно обновить прямо из сайдбара.
- USDT отображается как «₮» везде в интерфейсе.
- Поднят контраст вторичного текста по всему приложению.
- `npm run dev:server` — локальный запуск с тестовыми данными
  (серверы/домены/провайдеры/платежи/доход бота) без обращения к боевой БД.

## 1.2.1

- Исправлено кэширование статики: после самообновления браузер мог отдавать
  старый index.html со ссылками на удалённые JS-чанки предыдущей версии,
  из-за чего интерфейс частично ломался. HTML теперь всегда перезапрашивается,
  кэшируются только неизменяемые файлы `_next/static/`.

## 1.2.0

- Фронтенд полностью переписан на React 19 / Next.js / Radix UI / Framer Motion
  вместо Vue 3, с дизайн-системой postq-site.
- Категории записей стали полноценной сущностью с CRUD (раньше — фиксированный список из трёх).
- Раздел «Записи» переименован в «Ресурсы»; добавлен раздел «Рекламные компании» (заглушка).
- Настройки убраны из основного меню сайдбара — доступны только через профиль.
- Множество исправлений вёрстки и адаптивности под мобильные устройства.

## 1.1.1

- P&L: график прибыли по месяцам рисуется сразу при переходе в раздел из меню.
  Раньше он появлялся только после перезагрузки страницы.

## 1.1.0

- Быстрое продление продлевает запись на длину календарного месяца (31/30/28-29 дней)
  вместо фиксированных 30 дней.
- Настройки: карточка «Обновление панели» — текущая и доступная версия, проверка релизов
  на GitHub и обновление контейнера в один клик.
- Версия панели показывается в сайдбаре, при доступном обновлении рядом загорается точка.

## 1.0.0

- Первая версия: записи (серверы, домены, сертификаты), провайдеры, платежи, статистика,
  P&L, Telegram-уведомления, логи, 2FA.
