# Изменения

Версия панели живёт в `package.json` — сервер читает её оттуда и отдаёт в `meta.version`,
по ней же работает проверка обновлений. Релиз = тег `vX.Y.Z` в репозитории: панель
сравнивает свою версию с последним релизом (а если релизов нет — с максимальным тегом).

## 2.1.1

- Дашборд («Подписки»): новая карточка «Средний срок жизни подписчика»
  (1 / отток, в месяцах) рядом с карточкой «Отток» — `avgLifetimeMonths`
  в `/api/dashboard/summary`.
- Тёмная палитра фона стала светлее и единообразнее: фон сайдбара
  теперь того же цветового семейства, что и фон остального интерфейса,
  вместо заметно более тёмного/насыщенного оттенка. Обновлены и цвета
  вне globals.css, которые раньше были захардкожены отдельно и разошлись
  с темой — theme-color вьюпорта и background_color/theme_color в
  manifest.webmanifest.

## 2.1.0

- Финансы: новая вкладка «Отчёты» вместо «Курсы валют» — помесячная таблица
  (поступления, расходы, net, bookings/recognized MRR, ARPU, gross margin,
  churn), считается на лету по тем же агрегациям, что и Дашборд/P&L, без
  отдельного хранимого снепшота. Пустые месяцы без какой-либо финансовой
  активности не показываются. Курсы валют никуда не делись — их
  просмотр/обновление теперь только в сайдбаре.
- Прогноз (`/api/dashboard/forecast`) больше не пропускает текущий,
  ещё не завершившийся месяц — он попадает в ответ с флагом `projected`
  вместо того, чтобы сразу перескакивать на следующий. Незавершённые
  месяцы также больше не тянут вниз саму линию тренда — из истории для
  регрессии они исключены, пока месяц не закроется полностью.
  `/api/dashboard/summary` заодно отдаёт метрики предыдущего месяца, чтобы
  карточки могли показывать динамику без второго запроса.
- Прогноз будущих расходов на записи (renewals) — детерминированный
  график по `expiresAt`/циклу оплаты каждой записи, а не статистический
  тренд, в отличие от выручки.
- Мобильная шапка: лого с названием теперь только в ней — из сайдбара
  убраны, сама шапка стала плавающей (position: fixed), со скруглёнными
  углами и шириной по контенту, а не на всю ширину экрана. Нажатие на
  шапку открывает и закрывает боковое меню; сайдбар резервирует место
  под шапку, чтобы её первые пункты не оказывались у неё под низом.

## 2.0.3

- Настройки: новая карточка «Синхронизация с Bedolaga» — показывает время
  последней синхронизации и число транзакций/подписок/пользователей,
  плюс кнопка «Синхронизировать сейчас». Раньше проверить или запустить
  синк вручную было нельзя, хотя вкладка «Подписки» в Финансах целиком
  считается по этим локально засинканным данным (а не по тому же
  live-запросу, что и вкладка P&L).

## 2.0.2

- Хотфикс: в сайдбаре подсвечивался активным только пункт «Финансы» —
  остальные пункты (Записи, Реклама, Уведомления) никогда не получали
  класс active из-за несовпадения путей с конечным слэшем в проде.
- Тот же несовпадающий слэш заставлял переход между разделами откатываться
  на полную перезагрузку страницы вместо мгновенного перехода — отсюда
  ощущение медленной, дёрганой навигации.
- Вкладка «Подписки» в «Финансы» показывала одни нули без каких-либо
  пояснений, если синк с Bedolaga не настроен или упал с ошибкой — теперь
  вкладка отдельно сообщает, что интеграция не настроена, а настоящие
  сбои запроса показываются тостом, а не тонут молча.

## 2.0.1

- Хотфикс: карточки в «Финансы» на мобильных выстраивались в один
  столбец вместо сетки 2×N.

## 2.0.0

- Бэкенд полностью переведён на Python (FastAPI) — Node.js (`server.js`)
  убран из репозитория и из production-образа.
- Разделы «Дашборд», «Статистика» и «P&L» объединены в один раздел
  «Финансы» с вкладками: Подписки, P&L, Платежи, Курсы валют.
- «Провайдеры» перенесены во вкладку внутри «Ресурсов» — теперь один
  раздел с вкладками «Записи» и «Провайдеры».
- У записей появилось поле «Описание».
- Убрана нерабочая кнопка самообновления из настроек — версия панели
  видна в сайдбаре, обновление вручную (`docker compose pull && up -d`).
- Карточка записи: реальный срок истечения и дата в пиллах сверху,
  IP/провайдер выровнены сеткой со стоимостью/платежами ниже.
- Локальная разработка: `npm run dev` больше не грузит процессор на
  600–700% (Turbopack больше не сканирует весь репозиторий), `uvicorn --reload`
  больше не перезапускается от правок внутри `.venv`.

## 1.3.1

- Хотфикс: в модалке платежей кнопка добавления могла уезжать за пределы
  окна, если название валюты в селекте было длинным (например,
  «Российский рубль») — сетка `.quick-payment` не давала колонкам сжиматься.
  Текст в `AppSelect` теперь обрезается многоточием вместо переноса/
  раздувания ширины — тот же фикс защищает все остальные селекты в панели
  от такого же переполнения.
- Селекторы валюты (запись, платёж, продление, настройки) показывают знаки
  €/₽/₮ вместо полных названий — короче, не переносится, и устраняет саму
  причину переполнения выше.

## 1.3.0

- Единая типографическая шкала: 16 разномастных размеров шрифта собраны
  в 10 именованных токенов (`--text-2xs`…`--text-4xl`).
- Прогноз расходов на графике «Расходы по дням» — пунктирная линия на
  2 недели вперёд по датам продления активных серверов.
- Сортировка записей внутри категорий: вручную, по ближайшему платежу,
  по провайдеру, по стране.
- Карточка записи: акцент на статусе истечения (цвет/иконка совпадают
  с рамкой карточки), понятные подписи у сумм, убраны дублирующиеся
  элементы (повторный бейдж категории, лишняя строка «Платёж»).
- Плейсхолдер с первой буквой названия корректно показывается вместо
  битого favicon (в том числе если картинка не загрузилась).
- Сайдбар: карточка сводки разделена на «Ресурсы», «Финансы» и «Курсы
  валют»; в «Финансах» — доход и прибыль от бота за месяц с трендом
  к прошлому месяцу; курсы валют можно обновить прямо из сайдбара.
- USDT отображается как «₮» везде в интерфейсе.
- Поднят контраст вторичного текста по всему приложению.
- `npm run dev:server` — локальный запуск с тестовыми данными
  (серверы/домены/провайдеры/платежи/доход бота) без обращения к боевой БД.
