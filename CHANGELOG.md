# Изменения

Версия панели живёт в `package.json` — сервер читает её оттуда и отдаёт в `meta.version`,
по ней же работает проверка обновлений. Релиз = тег `vX.Y.Z` в репозитории: панель
сравнивает свою версию с последним релизом (а если релизов нет — с максимальным тегом).

## 1.1.1

- P&L: график прибыли по месяцам рисуется сразу при переходе в раздел из меню.
  Раньше он появлялся только после перезагрузки страницы.

## 1.1.0

- Быстрое продление продлевает запись на длину календарного месяца (31/30/28-29 дней)
  вместо фиксированных 30 дней.
- Настройки: карточка «Обновление панели» — текущая и доступная версия, проверка релизов
  на GitHub и обновление контейнера в один клик.
- Версия панели показывается в сайдбаре, при доступном обновлении рядом загорается точка.

## 1.0.0

- Первая версия: записи (серверы, домены, сертификаты), провайдеры, платежи, статистика,
  P&L, Telegram-уведомления, логи, 2FA.
